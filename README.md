# YOLO-Based Character Detection and Sequence Recognition on Low-Contrast Faded Bangladeshi License Plates Using Synthetic Fading Augmentation
Bangladeshi license plate recognition remains challenging under degraded visual conditions, particularly when fading and low contrast reduce character visibility. This study investigates synthetic fading augmentation to improve character detection and sequence recognition using lightweight YOLO-based models.

A dataset of 4,061 clean images, comprising 27 character and token classes, was divided into 3,480 training, 363 validation, and 218 test images. Two experimental families were conducted. The first compared a YOLOv8n baseline (Model A) with an augmented model (Model B) trained using the proposed BanglaPlateFade technique with an online augmentation probability of 0.60. The second compared YOLOv5su and YOLO11n models trained with and without synthetic fading. Performance was assessed using detection metrics, exact sequence accuracy, and character error rate (CER). Additionally, 67 real faded plate images were collected, of which 64 had ground-truth labels for sequence-level evaluation.
On the clean test set, Model B achieved 95.70% mAP@0.50 and 71.73% mAP@0.50:0.95, compared with 94.13% and 70.49% for Model A. Recall improved from 89.18% to 92.49%, while exact sequence accuracy increased from 72.48% to 78.44% and CER decreased from 3.28% to 2.86%. On the real faded dataset, Model B achieved 67.19% exact sequence accuracy and 8.07% CER, outperforming Model A, which achieved 46.88% and 18.49%, respectively. In the additional experiments, synthetic fading improved YOLOv5s exact matches by 14.1 percentage points (p = 0.0225), although this result did not remain significant after Bonferroni correction. The Model A–Model B improvement was statistically significant (p = 0.001). These findings demonstrate the potential of synthetic fading augmentation for improving Bangladeshi license plate recognition under the evaluated conditions. However, the limited real faded dataset and lack of complete verified bounding-box annotations restrict conclusions about real-world detection robustness. Future work should evaluate larger annotated datasets and additional degradation conditions, including fog, rain, and nighttime environments.
